# FallingTimber v1.4.2

FallingTimber v1.4.2 updates the plugin for Minecraft Java Edition and Paper
26.3.

## Changes

- Targets the Paper 26.3 API.
- Built and verified against Paper 26.3 build 40 with Java 25.
- Supports the new poplar tree through Paper's standard log tag, natural leaf
  data and `POPLAR_SAPLING` material.
- Keeps existing configuration, player preferences and statistics compatible.

## Installation

1. Stop the server.
2. Remove the older FallingTimber JAR from the `plugins` directory.
3. Copy `FallingTimber-1.4.2.jar` into the `plugins` directory.
4. Start the server and confirm FallingTimber v1.4.2 is enabled.

No configuration reset is required when upgrading from v1.4.1.
